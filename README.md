## Where to look first

- **If you care about statistics:** [the results table in the trading research](trading-research/#results). I tested more than fifteen trading rules against out-of-sample data. Almost all of them failed, and the README says so.
- **If you care about software design:** [how the Roblox round system works](roblox-win-or-die/#how-it-works). Every minigame plugs into one round manager through the same small interface.

## How these were built

I build with AI coding tools (Claude). The ideas, rules, specifications and testing are mine: I decide what gets built, write down how it should behave, test every change, and decide what stays. The AI writes much of the code. I use these projects to learn, so I ask for explanations as the code is written, and each project's README walks through how the code is organized and why.
